PROJECT DESCRIPTION

This project is a personal profile website created using HTML, CSS, JavaScript and jQuery. It demonstrates jQuery selectors, effects, animations, DOM manipulation and form handling.

TECHNOLOGIES USED

- HTML5
- CSS3
- JavaScript
- jQuery

PART 1 — SETUP AND PROFILE

Task 0 — jQuery Setup

Connected the jQuery library using a CDN. Used $(document).ready() to make sure the code runs after the page loads. Checked the connection using a console message: "jQuery is ready!"

Task 1 — Personal Profile

Created a personal profile section with a name, headline and short introduction. Used jQuery selectors to select and modify elements. Added a light and dark theme switch.

PART 2 — JQUERY EFFECTS

Task 2 — About Me

Created an About Me section with personal information and fun facts. Added Hide, Show and Toggle buttons using jQuery effects.

Task 3 — Image Effects

Added two visual illustrations to the website. Implemented fadeIn(), fadeOut() and fadeToggle() to control their visibility.

Task 4 — Collapsible Sections

Created three clickable headings with content panels. Used slideUp(), slideDown() and slideToggle() to show and hide the content.

PART 3 — DOM MANIPULATION AND FORMS

Task 5 — Skills List

Created a list of technical skills. Added an input field and buttons to add, prepend and remove skills. Used append(), prepend() and remove(). Empty input is not accepted.

Task 6 — Social Media Link

Added a social media link. Used the attr() method to change the link address.

Task 7 — Contact Form

Created a form with Name and Email fields. Used val() to get input values and text() to display the entered information on the page.

PART 4 — ANIMATIONS

Task 8 — Animated Skill Bars

Created skill bars for three technical skills. Their initial width is 0%. The Animate My Skills button uses the animate() method to increase the bars to different percentages. Clicking the button again resets the bars.

PROJECT SUMMARY

During this assignment, I learned how to use jQuery selectors, modify HTML elements, apply visual effects, manipulate lists, work with form inputs and create animations.
